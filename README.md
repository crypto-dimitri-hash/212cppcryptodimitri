# Горчак Дмитрий, 212 — задачи курса

Каждая папка — отдельная задача, в ней всё нужное. Сборка в любой папке одинаковая:

```bash
cd ~/cones/figures
g++ -std=c++17 -Wall -Wextra *.cpp -o figures
./figures
gnuplot plot_figures.gp
```

| Папка | Задача | Срок |
|---|---|---|
| `figures` | иерархия Point → Circle → Cone, фигуры из файла, объём по запросу: `./figures figures.txt 9` | 19.09 |
| `figures_list` | двунаправленный список `std::list`, порядок по площади и по объёму | 19.09 |
| `gauss_points` | точки по Гауссу внутри окружностей, блоки сетки, среднее, гистограмма | 26.09 |
| `gauss_demo` | проверка датчика нормальных чисел | 26.09 |
| `clusters` | поиск сгустков: волновой алгоритм и прорубание просеки | задел |

Результаты программы и рисунки gnuplot складываются в папку `out` внутри задачи.
Копии исходников для писем — рядом, с расширением `.txt` (`point.txt`, `point-h.txt`).
