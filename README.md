## Про название: конус, а не пирамида

В задании фигура названа пирамидой, но описана она четырьмя числами
`x, y, r, h`, то есть круглым основанием и высотой. Преподаватель уточнил,
что имеется в виду конус, поэтому класс называется `Cone`, а объём считается
по формуле

```
V = S · h / 3 = π · r² · h / 3
```

где `S` — площадь основания, полученная методом `area()` базового класса `Circle`.
Для сравнения в классе оставлен метод `volume_ngon(n)` — объём пирамиды
с правильным `n`-угольником в основании, вписанным в тот же круг:
при росте `n` он стремится к объёму конуса (проверяется прямо в программе).

## Иерархия классов

| Класс | Хранит | Добавляет | Вычислимые атрибуты |
|---|---|---|---|
| `Point` | `float x, float y` | — | `distance_to` |
| `Circle : Point` | `+ float r` | радиус | `area()` — площадь круга |
| `Cone : Circle` | `+ float h` | высоту | `volume()`, `height_at()` |

Все поля закрыты (`private`), доступ к ним — только через `get`/`set`.
Проверка значений (радиус и высота не могут быть отрицательными) живёт
внутри `set`-методов, поэтому испортить объект снаружи нельзя.
Площадь и объём не хранятся в полях, а считаются при каждом вызове,
поэтому они всегда согласованы с текущими значениями `r` и `h`.
Метод `print` виртуальный: один и тот же вызов через указатель на `Point`
печатает точку, круг и конус по-разному (полиморфизм).

## Сборка и запуск

Самый простой способ (нужен только g++):

```bash
cd ~/cones
bash build.sh
./bin/cones_app
gnuplot plot/plot_cones.gp
```

Через CMake (как на занятии 6):

```bash
cd ~/cones
cmake -B build
cmake --build build
./build/cones_app
```

Двунаправленный список (этап к 26.09):

```bash
./bin/cones_list
```

## Что создают программы

`cones_app` читает `data/cones.txt`, печатает таблицу свойств и сохраняет
три файла для gnuplot:

| Файл | Назначение |
|---|---|
| `cones_plan.txt` | вид сверху: `x y r h area volume` |
| `cones_field.txt` | сетка высот `z(x, y)` 121 × 121 для ландшафта |
| `cones_range.gp` | границы поля по x и y — их считает программа, а не человек |

Высота ландшафта в точке — максимум по всем конусам, поэтому там, где
основания пересекаются, виден более высокий конус.

`gnuplot plot/plot_cones.gp` рисует три картинки: `cones_plan.png` (круги
оснований), `cones_map.png` (карта высот) и `cones_landscape.png` (ландшафт).
Результаты сборки и рисунки в репозиторий не кладутся — они перечислены
в `.gitignore`.

## Данные

Строка файла `data/cones.txt` — четыре числа: `x y r h`. Строки, начинающиеся
с `#`, и пустые строки пропускаются. Строка с неверными данными не прерывает
чтение: программа сообщает её номер и причину и читает дальше — в файле
специально оставлена строка с отрицательным радиусом.
