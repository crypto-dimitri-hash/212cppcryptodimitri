# cones — фигуры на плоскости: Point → Circle → Cone

Автор: Горчак Дмитрий, 212

Программа читает из файла свойства фигур, создаёт точку, круг или конус,
считает площадь основания и объём и готовит данные для рисунков в gnuplot.

Папка рассчитана на `C:\msys64\home\wasdm\cones` (в терминале MSYS2 это `~/cones`).

Репозиторий: <https://github.com/crypto-dimitri-hash/212cppcryptodimitri>

## Сколько чисел — такая и фигура

| Числа в строке | Что создаётся | Вычислимые атрибуты |
|---|---|---|
| `x y` | `Point` — точка | — |
| `x y r` | `Circle : Point` — круг | `area()` — площадь |
| `x y r h` | `Cone : Circle` — конус | `area()`, `volume()` |

Объём есть только у конуса, поэтому он считается отдельно, по запросу:
номер нужной фигуры передаётся вторым аргументом командной строки.
Объём конуса `V = S · h / 3 = π · r² · h / 3`, где `S` — площадь основания,
полученная методом базового класса. Для сравнения в классе `Cone` есть метод
`volume_ngon(n)` — объём пирамиды с правильным n-угольником в основании,
вписанным в тот же круг: при росте n он стремится к объёму конуса.

Все поля закрыты (`private`), доступ к ним — только через `get`/`set`,
проверка значений (радиус и высота не могут быть отрицательными) — внутри
`set`-методов. Метод `print` виртуальный: один вызов через указатель на
`Point` печатает точку, круг и конус по-разному (полиморфизм).

Собранные программы складываются в `bin/`, всё, что создают программа и
gnuplot, — в `out/`. Обе папки в репозиторий не попадают (`.gitignore`).

Каждый скрипт gnuplot сначала сохраняет рисунки в файлы `png`, а в конце
показывает один из них в окне на экране (терминал `qt`). Окно держится
командой `pause`: чтобы закрыть его, нужно нажать Enter в терминале.

## Сборка и запуск

```bash
cd ~/cones
bash build.sh
./bin/figures
gnuplot plot_figures.gp
```

Объём одной фигуры по запросу (номер из таблицы):

```bash
./bin/figures figures.txt 9
```

Двунаправленный список и упорядочивание по площади и по объёму:

```bash
./bin/figures_list
```

Облако гауссовых точек, сетка блоков и поиск сгустков:

```bash
./bin/points                    # 20 точек на конус, облако без наклона
./bin/points figures.txt 40 0.7 # 40 точек на конус, наклонённое облако
gnuplot plot_points.gp
```

Программа `points` рассыпает вокруг каждого конуса точки по двумерному
нормальному закону (центр конуса — среднее, `sigma = r / 2`, поэтому почти
все точки попадают внутрь основания), приписывает каждой точке две целые
координаты её блока сетки 10 × 10, строит матрицу расстояний, подбирает
порог по минимальному покрывающему дереву, строит двоичную матрицу связей
и ищет кластеры двумя способами — обходом («прорубание просеки») и волновым
алгоритмом («лесной пожар»). Отдельно сравнивается поиск ближайшей точки
полным перебором и по блокам сетки.

Проверка самого датчика случайных чисел — одномерное и двумерное
нормальное распределение:

```bash
./bin/gauss_demo          # выборка из 5000 чисел
./bin/gauss_demo 20000    # выборка другого размера
gnuplot plot_gauss.gp
```

Программа печатает среднее и отклонение выборки и доли значений внутри
одной и двух сигм (теория: 68.3 % и 95.4 %), а также сохраняет шесть
двумерных облаков: круглое, вытянутое вдоль оси абсцисс и вдоль оси
ординат (при `rho = 0` форму задают только разбросы) и три облака при
`rho = 0.7`, `-0.7` и `0.95` (при равных разбросах форму задаёт только связь).

Копии исходников в `.txt` обновляются скриптом:

```bash
bash make_txt.sh
```

## Что создают программы

| Файл в `out/` | Назначение |
|---|---|
| `plan_points.txt`, `plan_circles.txt`, `plan_cones.txt` | вид сверху, отдельно по типам фигур |
| `field.txt` | сетка высот `z(x, y)` 121 × 121 для ландшафта |
| `range.gp` | границы поля по x и y — их считает программа |
| `plan.png`, `map.png`, `landscape.png`, `points3d.png` | рисунки по фигурам |
| `points.txt`, `grid_lines.txt` | точки с номерами блока и кластера, линии сетки |
| `points_clusters.png`, `points_grid.png` | рисунки по кластерам и сетке |
| `gauss1d.txt`, `gauss2d_*.txt` | выборка и шесть двумерных облаков |
| `gauss1d.png`, `gauss2d_sigma.png`, `gauss2d_rho.png` | гистограмма и облака |

Высота ландшафта в точке — максимум по всем конусам, поэтому там, где
основания пересекаются, виден более высокий конус.

## Что дальше

Матрица связей строится полным перебором пар; её можно строить по блокам
сетки, взяв размер блока равным порогу, — тогда для каждой точки достаточно
проверить соседние блоки, а не всё облако.

Вывод программ на английском, комментарии в коде на русском — как в прошлых работах.
